## Why

Criar um aplicativo simples e funcional de lista de compras para ajudar usuários a gerenciar suas compras do dia a dia, permitindo adicionar itens com preço e quantidade, e visualizar o total em reais.

## What Changes

- Criar novo projeto React Native com Expo Managed Workflow
- Configurar TypeScript e NativeWind
- Implementar UI de lista de compras com input e botão adicionar
- Permitir adicionar preço e quantidade aos itens
- Exibir total da compra em reais no cabeçalho

## Capabilities

### New Capabilities

- `shopping-list-app`: Aplicativo de lista de compras com input, botão adicionar, campos de preço e quantidade, e total em reais

### Modified Capabilities

- Nenhum - novo projeto

## Impact

- Novo projeto React Native com Expo
- Dependências: react-native-reusables, nativewind
- Arquitetura: Component-based com hooks para estado
